# Erdős Problem 699

二項係数どうしの共通素因数を調べる研究記録です。**問題全体は未解決です。**

> 任意の整数 $1\le i<j\le n/2$ に対して、
> $\binom ni$ と $\binom nj$ は素数 $p\ge i$ を共有するか？

## 2026年9月23日の研究

[任意次数の桁和降下](research/i3/i3_uniform_digit_descent_2026-09-23.md)を追加しました。$H=s_{p^d}(n)$、$A=s_{p^d}(j)$ とし、小さい行の全奇素因数から定める法 $M(H)$ が $\gcd(n-H,j-A)$ を割れば、**反例から小さい反例へ降下できる**と証明しました。桁数や素数の大きさに上限・下限を置きません。
ただし、この条件を満たす基数が必ず存在することは未証明です。18,711組の小さい行と添字、138,374件の付値移行、3,400件の桁の結合を検算しました。今後の主対象は、全基数で降下が失敗する配置の排除です。

[四次の桁多項式の完全分類](research/i3/i3_quartic_digit_classification_2026-09-23.md)を追加しました。残っていた2+2分配を、二次式の合成族と明示的な四次族に分類しました。整数係数条件まで追うと、**どちらも全整数値で $F(x)\equiv2\pmod4$** となり、反例には使えません。これにより桁和からの素数上界を次数4以下の全末尾へ拡張しました。
任意次数でも、最高次係数比が因子分配から $mt=d_1+2d_2-v$ と決まることを証明しました。五次以上と、数値の条件から多項式条件へ移せない領域は残っています。

[全素因数の桁和評価と、任意次数の因子分配](research/i3/i3_digit_height_budget_and_factor_degrees_2026-09-23.md)を追加しました。
$Q_1=(n-1)/\delta_1$、$M_1=\Omega(Q_1)$、$H_1=\max_{p\mid Q_1}s_p(n)$ とすると、反例には **$n<16\cdot7^{M_1}(H_1+2)^{2M_1^2+4M_1}$** が必要です。j の偶奇を問わず、重複込みの素因数が少なければ大きい桁和を強制します。
また、桁多項式 F−1 の両因子群は次数 m/3 以上、F−2 の三因子群は各 m/2 以下と証明しました。四次の1+3分配を排除し、その後の続稿で2+2分配も分類しました。13恒等式などを検算しました。一般枝の完全解決には至っていません。

[一般の偶数 j：高い冪と Kummer ブロックの素数台](research/i3/i3_multiplicity_budget_and_fresh_support_2026-09-23.md)を追加しました。
第一曲線の導手に現れない冪を $\mathcal E=abP^2/\mathcal Q$ で測り、$T^3\mathcal E$ に明示的上限を証明しました。
$G\sim\log_2u$ では $T,\mathcal E=u^{o(1)}$。一方、$A,B,C,R,S$ を割り補助因子 $abP$ を割らない素数の積 $F_K$ は $u^{1-o(1)}TP$ 以上が必要です。
$F_K$ が有界なら $G\ge2\log_2u-O(\log\log u)$ へ下限が強まります。
18恒等式と直接の二曲線を検算しました。全ての偶数分岐に適用できますが、これらを満たす一般枝と奇数 j は残ります。

## 2026年9月21日までの研究

[増大するGに対する平方枝の一様排除](research/i3/i3_gap_square_obstructions_2026-09-21.md)を追加しました。
**$\delta_2TPW_*$ は全ての $G$ で非平方**と証明しました。
中心方程式の先頭係数 $\delta_2\gamma m2^{G-1}$ が平方なら、$\gamma T\equiv7\pmod8$、$G\ge(u+7)/2$ が必要です。
$T=1$ を含む平方の $T$ では先頭係数の平方も不可能。新たな外部表を使わず、因数分解と合同式で示しています。
両係数が非平方となる領域は残っています。

[増大する指数差と第二のFrey曲線](research/i3/i3_growing_gap_and_auxiliary_frey_2026-09-21.md)を追加しました。
偶数 $j$ の和の式から、最小判別式の2進指数が $2G-14$ の半安定曲線を構成しました。
$R_F=\operatorname{rad}_{\ge5}(mTPW_*)$ として **$G<(9/2)R_F\lceil\log_2(6R_F)\rceil^2+52$**。
$G$ が対数的な下限を超えても、$R_F=o(G/(\log G)^2)$ の枝は排除できます。
公開全曲線表と残存ケースの因数分解から、$R_F>166$、$mTPW_*$ に素因数 $p\ge13$ が少なくとも一つ必要なことも証明しました。
$G,R_F$ が共に速く増える全領域は未解決です。

[新チャット成果の統合と指数差の有効有限化](research/i3/i3_new_chat_integration_and_effective_gap_2026-09-21.md)を追加しました。
偶数 $j$ では $G=u-4v_2(j)$ として、$q=Tg_0h_0W_*$ を同定し、$W_*$ の全素数冪を含む平方合同式へ強化しました。
判別式と導手をつなぐことで、**$u<(6561/4)2^G(G+10)^2+124$** という計算可能な上限を得ました。
従って $u\ge2^{42}$ なら $G>\tfrac12\log_2u$ が必要です。$G$ がさらに速く増える領域は未解決です。

[二次捻りとKummer補助因子の続稿](research/i3/i3_quadratic_twist_and_kummer_support_2026-09-21.md)を追加しました。
曲線の2進条件を保ったまま、悪い還元から除ける因子を6乗から**3乗**へ強めました。
残る導手の量は、Kummerの補助因子を使って
$\mathcal Q=\operatorname{rad}_{\ge5}(ab)\operatorname{rad}_{\ge5}(\operatorname{cf}_3(G_0H_0))^2$ と正確に書けます。
3乗を除いたこの小さい量にも、$u$ の明示的上限と増大が遅い枝の排除が適用できます。
二次捻りだけでは、残った5以上の素数を更に除けないことも証明しました。

[増大する判別式を楕円曲線へ移す続稿](research/i3/i3_discriminant_support_and_elliptic_curve_2026-09-21.md)を追加しました。
反例の曲線には最小判別式の2進付値76以上が必要ですが、公開全リストの対象では最大48・51。
これにより、判別式の素因数が全て11以下の枝と、異なる奇素因数の積が500以下の枝を、指数無制限で排除しました。
さらに6乗因子を取り除き、判別式の素因数自体が増える一部の枝にも拡張しています。
全1,813,534行を検算し、リストの完全性は外部計算に依存することを明記しました。
既知の判別式・導手の定理から、$Q=R_WR_s^2$ に対する $u$ の明示的上限も導出しました。
これにより $Q=o(u/(\log u)^2)$ の速度で増大する枝は不可能です。具体的には $u\ge2^{40}$ なら $R>u^{1/4}$ が必要です。

基盤は[4チャットの統合](research/i3/i3_four_chat_integration_2026-09-21.md)と
[終端判別式3000以下の排除](research/i3/i3_terminal_thue_mahler_2026-09-21.md)です。
現在の必要条件は $u\ge51$ と $(16000/9)M^3<2^u$。
後者は外部の完全性定理に依存し、33,456点の検算と268形式の対応はローカルで再生できます。
外部表を使わない条件も $(9088/27)M^3<2^u$ に改善しています。
$u\ge51$ は[既存の独立証明書](research/i3/i3_cubic_discriminant_minima_2026-09-21.md)によります。
曲線の悪い還元に残る素数集合が増大する全領域は未解決です。
