入力・応答はバイト列を変えていません。XML内の旧パスとSHA-256も保存しています。
[固定因子の検算](../scripts/audit_i3_fixed_blocks.py)では、集約応答と元のバッチのハッシュ・内容の対応も確認します。
全ての応答が計算の完了を示すわけではなく、時間制限に達した記録も残しています。
数学的結論に使う応答の範囲は各ノート・検算器で明示しています。
