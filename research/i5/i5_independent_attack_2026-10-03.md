**一般 i=5 と問題699の完全解決は得ていない。** 本稿で新しく閉じるのは、奇数9類・行3と偶数64類・行2で、正の桁重みが4、6、8、非零の正次数桁が二か所以内となる全族である。さらに第8節では、桁の位置数に制限を置かず、奇数9類・行3の全候補底で桁和H>=9を証明する。まず重み4を詳しく証明し、第7節で6、8へ拡張する。

## 1. 依存と未解決の境界

外部 [Bennett--Filaseta--Trifonov 原論文](https://people.math.sc.edu/filaseta/papers/BFTpaper0207.pdf)の Theorem 2.1 は、近接する 2冪・3冪の余因子の最大値に指数0.285の下界を与える。支持01の AB<C n^(3/5) に対し、これだけでは一般枝を閉じない。Mahlerによる積のより強い下界は同原論文の導入で非有効と明記されており、既存の10^87という有限域と接続できる数値閾値は得られていない。

以下の追加族の尾部排除は新たな外部近似定理を用いない。ただし、偶数側の支持01への先行還元には既存の外部BFT依存がある。

## 2. 正確な入力

奇数9類では s=3,t=4、偶数64類では s=2,t=3 とする。
行sの候補素数 p>=5 の完全付値 q=p^e を取る。p=5が候補に残るにはe>=2が必要なので、常にq>=7。
通常のq進展開で

```math
n=F(q),\quad j=J(q),\quad F(0)=s,\quad J(0)=u\in\{0,\ldots,s\},
\quad 0\le J_k\le F_k
```

であり、完全付値のため F_1>0。j>=6 と j<=n/2 により J=u および J=F-s+u は除外される。
正の桁重みが4で二か所以内なら、一位置の F=s+4X または

```math
F=s+aX+bX^m,\quad a,b\ge1,\quad a+b=4,\quad m\ge2,
\quad J=u+cX+dX^m,\quad0\le c\le a,\quad0\le d\le b
```

という形しかない。端点 (c,d)=(0,0),(a,b) を除く。
隣接行tの復元分母はどちらの向きでも D'_t<=5、かつ D'_tは1または5である。従って

```math
A(q):=F(q)-t\mid 5\prod_{v=0}^t(J(q)-v). \tag{1}
```

ここで単に D'_t<=5 だけから(1)を導いたのではなく、D'_t|5を用いた。

## 3. 指数mを一次式へ圧縮する

```math
A(X)=bX^m+aX-1,\quad h=bc-ad,\quad k_v=d+b(u-v),\quad L_v(X)=hX+k_v.
```

すると整数係数の恒等式

```math
b(J(X)-v)=dA(X)+L_v(X) \tag{2}
```

が成立する。(1)へb^(t+1)を掛けて(2)を使うと

```math
A(q)\mid5\prod_{v=0}^t L_v(q). \tag{3}
```

常に |h|<=ab<=4、|k_v|<=K_t:=3(t+1)。

h=0 なら、端点除外から 0<d<b である。従って k_v は b を法として d と合同で全て非零であり、(3)から

```math
n\le t+5K_t^{t+1}. \tag{4}
```

を得る。

## 4. 低次数では整数終結式が非零

h!=0 とする。L_vの根がAの根なら、その根は有理数である。
Aには負の有理根がない。実際、有理根定理より負の有理根は-1/r、r|b。mが奇数ならA(-1/r)<0。
mが偶数でr>=2なら b/r^m<=3/4<1なのでやはり負。r=1なら A(-1)=b-a-1=3-2a!=0。

Aの正の根alphaは一つだけで、F(alpha)=s+1。非端点の係数大小により

```math
u<J(\alpha)<u+1.
```

従って(2)のL_v(alpha)=b(J(alpha)-v)は、整数vに対し非零。A(0)=-1も考えると、AとL_vに共通根はなく、整数

```math
R_v=b(-k_v)^m+a(-k_v)h^{m-1}-h^m\ne0 \tag{5}
```

を得る。符号を除いてRes(A,L_v)である。
さらに h^m A(X)-R_v は L_v(X)で整数係数のまま割れる。よって(3)から

```math
A(q)\mid5\prod_{v=0}^tR_v. \tag{6}
```

ここでは不要な係数5^mを導入せず、各整数Bezout恒等式を掛け合わせた。
2<=m<=t+1では

```math
|R_v|\le C_t:=3K_t^{t+1}+3K_t4^t+4^{t+1},
\qquad n\le t+5C_t^{t+1}. \tag{7}
```

## 5. 高次数と共鳴

m>=t+2、h!=0 とする。全L_v(q)が非零なら、q>=7、t<=4により

```math
|L_v(q)|\le4q+15<7q,\qquad A(q)>q^m/2.
```

従って(3)から q^{m-t-1}<10*7^(t+1)。特に

```math
q<Q_t:=10\cdot7^{t+1},\qquad
n<t+5(7Q_t)^{t+1}. \tag{8}
```

一方 L_v(q)=0 なら (2)より b(j-v)=d(n-t)。d=0ならj=v<=4、d=bならn-j=t-v<=4となり、尾部では不可能。
0<d<bで、d/b>1/2なら j<=n/2 と直線式からn<=2bt<=24。残る d/b<=1/2 を既約a'/b'にする。
この直線は実際のセル(t,v)を通り、b'<=b<=3。既存の零直線補題を用いて

```math
n\le60(8b')^4+3\le19,906,563. \tag{9}
```

共鳴を「終結式はいつも非零」と言って無視していない。(5)は多項式の共通根についての主張、L_v(q)=0は整数評価についての別分岐である。

一位置 F=s+4X では J=u+cX、1<=c<=3。4(J-v)=c(4X-1)+c+4(u-v)の全定数が非零なので

```math
n\le t+5(4t+3)^{t+1}. \tag{10}
```

## 6. 結論と厳密検算

(4)、(7)--(10)の上限は全て10^87未満である。従って既存有限域と接続し、**重み4・二位置以下の族は、全ての底q、完全付値e、次数mについて反例にならない。**

| 向き | s | 最小桁和の場合に追加で必要となる条件 |
|---|---:|---|
| 奇数9類・行3 | 3 | H=7なら、正次数の非零桁が少なくとも3か所 |
| 偶数64類・行2 | 2 | H=6なら、正次数の非零桁が少なくとも3か所 |

これは少なくとも一底についての主張より強く、その行の全候補素数冪それぞれに課す条件である。Hがさらに大きい一般桁、三・四位置の重み4、素数個数・桁重みが共に増える一般枝を排除したとは主張しない。

## 7. 重み6、8への拡張

M=a+bが6または8の場合も、第2--5節の整数恒等式はそのまま成立する。非零終結式の証明に必要なのはAに負の有理根がないことだけである。
負の有理根-1/rがあるならmは偶数で、r|bかつ

```math
b=r^{m-1}(a+r).
```

r=1ではM=2a+1が奇数。r=2,m=2ではM=3a+4となり、Mが偶数ならaが正の偶数なのでM>=10。
r=2,m>=4ではM>=25、r>=3ではM>=13である。従って偶数M<=8に負の有理根はない。
正の根でのJの開区間は変わらず、全R_vは非零である。

次の一様な定数に置き換える。

```math
H_M=\lfloor M^2/4\rfloor,\quad K_{M,t}=(M-1)(t+1),
\quad D_M=H_M+\lceil5(M-1)/7\rceil,
```

```math
C_{M,t}=(M-1)K_{M,t}^{t+1}+(M-1)K_{M,t}H_M^t+H_M^{t+1}.
```

低次数2<=m<=t+1にはn<=t+5C_(M,t)^(t+1)。高次数m>=t+2で共鳴がなければ

```math
|L_v(q)|\le D_Mq,\quad q<10D_M^{t+1},
\quad n<t+5(10D_M^{t+2})^{t+1}.
```

共鳴の既約分母はb'<=M-1<=7なのでn<=60(8(M-1))^4+3。一位置族にはn<=t+5(Mt+M-1)^(t+1)。
これらの最大値は、M=8,t=4でさえ3*10^45未満である（浮動小数点に依存せず検算器で10^87との整数比較を行う）。
従って、**M=4、6、8の二位置以下は全底・全次数で排除される。**
全候補素数冪について、奇数行3でHが7、9、11のいずれか、偶数行2でHが6、8、10のいずれかなら、正次数の非零桁は少なくとも3か所でなければならない。
これは一般の桁和の上限を証明したものではない。M=10以降には負の有理根が実際に生じる（a=2,b=8,m=2ではA=8X^2+2X-1が-1/2を根に持つ）ため、全終結式の非零性を同じまま無制限に外挿できない。

## 8. 桁の位置数に制限を置かない法24の障害

全候補qは2、3と互いに素なのでq^2≡1 mod24である。正次数の奇数位置にある係数の総和をOとする。
正の桁重みMに対し、全次数・全位置数について

```math
F(q)-s\equiv M+(q-1)O\pmod{24},\qquad1\le O\le M \tag{11}
```

が成立する。O>=1はF_1>0による。

### 奇数9類・行3は全候補底でH>=9

n≡9 mod72ではn-3≡6 mod24。M=4なら(11)は(q-1)O≡2 mod24を要する。
mod8では、q≡3,O=1またはq≡7,O=3しかない。一方mod3ではq≡-1,O≡2を要し、どちらにも矛盾する。
従って**M=4は、三位置・四位置を含め全桁構造で不可能**。
Mは偶数であり、既存のM=2排除を合わせるとM>=6、すなわち

```math
\boxed{\text{奇数9類・行3の全候補素数冪について }H\ge9.} \tag{12}
```

を得る。さらにq≡11,23 mod24ではM=6にも1<=O<=6の解がなく、これらの底はH>=11を要する。
第7節と合わせ、M=6、8の場合にも正次数の非零桁は少なくとも三か所である。
従来の条件付きH_*<=7に対する素数個数下限は、(12)によって空の仮定となり、置き換えられる。

### 偶数64類・行2の全底が最小桁和なら、5の位置と個数の奇偶が決まる

n≡64 mod72ではn-2≡14 mod24。M=4の(11)に許される型は正確にq≡11 mod24、O=1のみである。
全候補qがH=6なら、全てのq≡11 mod24。単元群の指数が2なので、各素数p≡11 mod24、完全付値eは奇数となる。
行2の復元分母はD'_2=2または10で、n-2=D'_2∏q。法24の積から

```math
14\equiv D'_2\,11^k\pmod{24}
```

を要し、D'_2=10、kが奇数という場合だけが残る。従ってv_5(n-2)=1である。
既存のH_*<=6に対するk>=6と合わせるとk>=7を得る。
特にv_5(n-2)が1でなければ、少なくとも一候補底でH>=8が必要である。

これらの法24型は有限群全体の厳密な閉包計算で確認する。qや次数を有限個だけ調べた外挿ではなく、q^2≡1と全係数和Oによる普遍証明が根拠である。
