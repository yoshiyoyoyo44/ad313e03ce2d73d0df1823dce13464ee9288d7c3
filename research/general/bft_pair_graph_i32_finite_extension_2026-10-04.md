# i=32 の全 n 閉鎖：913/1000 尾部と有限証明書の延長

2026年10月4日。元の Erdős 問題699 の p≥i 版を扱う。

**定理。全整数 32<j≤n/2 に対し、C(n,32) と C(n,j) は素数 p≥32 を共有する。**

[六添字のBFTグラフ証明](bft_pair_graph_closeout_six_indices_2026-10-04.md)
で証明された余因子積の下界を使い、i=32 の尾部を n≥10^116 で閉じる。
その下に残った有限範囲を、初期上限10^116からの新しいCRT還元証明書で完全に覆う。
指数に上限を仮定することも、有限探索を無限域の代用とすることもない。

## 1. 10^116 から上の全尾部

同稿の記号で h=31、m=11、b=21、d=32、S=231、D=21、
c_32=32、A=32!/32=31! である。
N=10^116 とする。

BFT Theorem 2.1 の14組の最大値条件と同稿の五分岐の証明は、

```math
P>(n−31)^{913/1000}
```

を与える。三方向被覆と小素数付値の上界は

```math
P^32 ≤ (31!)^32 4^(−231)
        (n/(n−31))^1024 n^21
```

を与える。

N>2·31·1024 かつ N>2·31·913·32 なので、二回の Bernoulli 評価により、
反例は全 n≥N で

```math
4^231000 n^8216 < 2^1001 (31!)^32000             (1)
```

を満たす必要がある。8216=913·32−1000·21>0 である。

n=N ではこの反対向きの厳密比較が成立する。巨大な整数を使わない証明もある。
4^5>10^3、31!<10^34、2^1001<10^302 なので

```math
4^231000 N^8216
 > 10^(600·231+116·8216)
 = 10^1091656,

2^1001 (31!)^32000 < 10^(302+34·32000)=10^1088302.
```

十進指数の差は3354>0。左辺は n とともに増えるので、(1)は全 n≥N で不可能である。

## 2. 初期上限10^116の有限CRT還元

既存 [9月27日証明書](september27_integration.md) の二余因子積による有限還元を、
新しい**有限の**初期上限 N=10^116 で実行した。
使う一般補題と独立検証器は原本REPORT第4–5節、product_bootstrap.py、
verify_product_bootstrap.py に保存されている。

L=2,000,000 とし、L≤n≤N に反例があると仮定する。
C_i(N) は余因子積上界の d 乗である。
最小二余因子 a≤b は

```math
(ab)^(m/2) ≤ a b^(m−1) ≤ P,
ab ≤ floor(C_i(N)^(2/(dm))).
```

を満たす。n がこの積上限に2hを加えた値を超えれば、
a<q^f、b<p^e であり、差δ=a p^e−b q^f を固定したときに
aまたはbの一つの剰余代表で全候補を列挙できる。
p^e,q^f≤N が指数の**正当な有限上限**を与える。
係数区間を全部走査せず、全素数対・全指数対・全 −h≤δ≤h を扱う。

新証明書の上限鎖は次である。

```math
10^116
 → 16485879167611651877
 → 46682539
 → 1955628.
```

最終上限はL未満なので、全 L≤n≤10^116 の反例がない。
[証明書](../../data/certificates/i32_bft_finite_extension_2026-10-04.json)
は全三段の入力、係数上限、指数対数、残存候補、出力上限を明示する。

生成器は最大行余因子による必要条件で候補を落とした。
独立検証器は保存した証明書を読み直し、反対のCRT座標から全候補を再構成して、
実際の C(n,32) を作り、小素数を除いた Q に対する

```math
4^231 Q^32 > n^693
```

を確認した。三段の確認件数は10,946、11,137、10,114、合計32,197件である。
上限鎖の連続性と各段の完全性も確認した。
実行前後に原本40ファイルのSHA-256が一致し、原本を書き換えていない。

[生成と独立検算](../../scripts/audit_i32_bft_finite_extension_2026_10_04.py)と
[結果](../../data/results/verification_i32_bft_finite_extension_2026_10_04.json)を保存した。

## 3. 先頭範囲の完全被覆と境界

既存 i=32 の先頭証明書は

```math
66≤n≤1999999
```

を13,539整数区間と7,144単一点で覆う。
区間では小素数部分の上界と重み付き積の矛盾を厳密な有理数対数区間で確認し、
単一点では p≥32 の実際の二項係数付値と全桁Kummer条件の交差を確認する。

この証明書を今回、新しい最終上限1,955,628と結合して実際に再生した。
各タイルの連続性、素数性、全候補j、全区間の厳密な正値性を再確認し、
保存された独立再生結果と完全に一致した。

n<66 には整数32<j≤n/2が存在しない。
先頭範囲の終端1,999,999と有限CRT範囲の開始2,000,000は隣接し、
有限範囲の終端10^116と尾部の開始10^116は重なる。
従って全 n,j が覆われる。

[先頭再生器](../../scripts/audit_i32_bft_prefix_dependency_2026_10_04.py)と
[結果](../../data/results/verification_i32_bft_prefix_dependency_2026_10_04.json)を保存した。
原本40ファイルのハッシュはこの実行前後にも不変である。
