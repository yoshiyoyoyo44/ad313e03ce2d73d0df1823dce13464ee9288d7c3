# BFT の三組の積による i=27,30,33 の全 n 閉鎖

2026年10月4日。対象は元の Erdős 問題699、すなわち整数
1≤i<j≤n/2 に対して、二つの二項係数を割る素数 p≥i の存在である。

**定理。i∈{27,30,33} では、全ての許される n,j について元の結論が成立する。**

この三添字については、既存の n≤10^87 の有限証明書と、本稿の
n≥10^87 の尾部証明を接続する。一般の問題699を解決したとは述べない。
最大付値行の保存集合を全て調べる必要はなく、同じ積評価が全配置を覆う。

## 1. 外部の明示定理と三組の選択

使う外部入力は Bennett--Filaseta--Trifonov,
[On the factorization of consecutive integers](https://people.math.sc.edu/filaseta/papers/BFTpaper0207.pdf),
Theorem 2.1、印刷頁4（PDFの0始まり頁番号3）である。原文を独立に確認した。

表中の素数 p,q と指数 λ=λ(p,q) に対し、非負整数 k,l,x1,x2 が

```math
|p^k x1 − q^l x2| ≤ 100
```

を満たせば、p^k x1≤1000、明示された40例外のいずれか、または

```math
max(x1,x2) > min(p^k x1,q^l x2)^λ
```

となる。例外は両順序を含み、例外の二数の最大値は1,771,561である。
x1,x2 に互いに素という仮定はない。k,l の上限もない。

本稿で使う表の三行は次であり、六つの素数は全て異なる。

|p|q|λ|
|---:|---:|---:|
|2|7|259/1000|
|3|11|329/1000|
|5|13|163/1000|

合計は751/1000である。各 λ は同定理の明示した小数をそのまま有理数にした値であり、Corollary 2.3 の非明示閾値を使わない。

## 2. 最大付値行の余因子積の普遍的下界

固定した i≥14、i−1≤100 に対し、小素数 p<i の最大付値を

```math
E_p=max_{0≤r<i} v_p(n−r),  r_p∈argmax_{0≤r<i} v_p(n−r),
a_p=(n−r_p)/p^{E_p},  P=∏_{p<i} a_p
```

とする。全 a_p は正整数である。r_p の相異性を仮定しない。

n−(i−1)>1,771,561 なら、三組それぞれについて

```math
p^{E_p} a_p=n−r_p,
q^{E_q} a_q=n−r_q,
|p^{E_p}a_p−q^{E_q}a_q|=|r_q−r_p|≤i−1≤100.
```

よって Theorem 2.1 の小さい値と例外を全て除外できる。
三組を適用し、a_p a_q≥max(a_p,a_q) と、残る a_p≥1 を使うと

```math
P ≥ (a_2 a_7)(a_3 a_11)(a_5 a_13)
  > (n−(i−1))^{(259+329+163)/1000}
  = (n−(i−1))^{751/1000}.                       (1)
```

同じ行を選ぶ素数があっても、BFT の差≤100という仮定を満たす。
差0の場合を別に確認することもできる。p^{E_p},q^{E_q} が同じ
N=n−r を割れば a_pa_q≥N、従って max(a_p,a_q)≥√N>N^λ。
本稿の各 λ<1/2 なので、この場合にも必要な下界は成立する。

## 3. 反例の余因子積上界を再導出する

反例を仮定し、h=i−1、m=π(i−1)、c_i=∏_{p<i}p^{v_p(i)} とする。
以下は既存の[三方向の重み付き積](weighted_cover_and_integration_2026-09-26.md)
および[余因子法](handoff_integration_2026-09-26.md)の一般補題である。

A=C(n,i) の p≥i 部分を Q とする。反例の全 Kummer 条件により、
互いに素なセル B_{s,u}=gcd(gcd(Q,n−s),j−u) の積が Q に等しい。
b=ceil(2h/3)、d=3b−h、S=b(b+1)/2 とし、

```math
w_s=max(0,s−(h−b)),
x_u=max(0,b−u), z_v=max(0,b−v)
```

を選ぶと、全セルで w_s+x_u+z_{s−u}≥d である。
三方向の重み総和はそれぞれ S なので、行・列・対角線の整除性と
(j−u)(n−j−u)≤n²/4 から

```math
Q^d ≤ 4^{−S} n^{3S}.                            (2)
```

小素数 p<i の二項係数付値は E_p−v_p(i) 以下だから、

```math
Q ≥ c_i P (n−h)^i/(i! n^m).
```

従って D=3S−d(i−m) と置けば

```math
P^d ≤ (i!/c_i)^d 4^{−S}
      (n/(n−h))^{id} n^D.                       (3)
```

対象三添字は全て合成数なので c_i=i、i!/c_i=(i−1)! である。
素数の添字にこの等式を無断で流用しない。

|i|m|b|d|S|D|
|---:|---:|---:|---:|---:|---:|---:|
|27|9|18|28|171|9|
|30|10|20|31|210|10|
|33|11|22|34|253|11|

## 4. 10^87 での厳密比較と全尾部

N=10^87、n≥N とする。全三添字で

```math
N > 2idh,    N > 2h(751d).
```

Bernoulli により (1−h/n)^{id}>1/2、
(1−h/n)^{751d}>1/2 なので、(3)と(1)からそれぞれ

```math
P^{1000d} < 2^{1000} ((i−1)!)^{1000d}
              n^{1000D}/4^{1000S},

P^{1000d} > (n−h)^{751d} > n^{751d}/2.
```

従って反例の必要条件は

```math
4^{1000S} n^{751d−1000D}
   < 2^{1001} ((i−1)!)^{1000d}.                 (4)
```

一方、検算器は N において以下を**整数の直接累乗比較**で確認する。

```math
i=27: 4^171000 N^12028 > 2^1001 (26!)^28000,
i=30: 4^210000 N^13281 > 2^1001 (29!)^31000,
i=33: 4^253000 N^14534 > 2^1001 (32!)^34000.
```

左辺の n の指数は全て正で、Bernoulli の二条件も n とともに保たれる。
よって全 n≥N で (4) に矛盾する。

既存の [9月27日有限域証明書](september27_integration.md) は
i≥5,n≤10^87 を覆うため、三添字は全 n で閉じる。
有限証明書の検算を今回の小さい検算器が再実行したという意味ではない。
尾部と有限域の依存先を区別する。
