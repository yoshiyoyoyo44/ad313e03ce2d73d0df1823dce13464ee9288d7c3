# 二位置の桁に対する、素数個数によらない全次数の上限

2026年10月3日。元問題の完全解決を目指した独立検討。
[既存の桁降下](adjacent_row_digit_descent_2026-10-03.md)を用いる。
**問題699全体は未解決。本稿は仮定を明示した有限化補題である。**

## 1. 一つの底だけから得る上限

反例を仮定する。各小素数 $`p<i`$ の最大付値行を一つずつ選び、そのどれでもない行を非最大行と呼ぶ。
非最大行 $`r`$ では、候補素数の完全付値を復元した積 $`Q'_r`$ に対して

```math
n-r=D'_rQ'_r,\qquad D'_r\mid L_i:=\operatorname{lcm}(1,\ldots,i),
\qquad Q'_r=\prod_{w=0}^rB'_{r,w}
```

である。各セルは互いに素で、$`B'_{r,w}\mid n-r,j-w`$ を満たす。
分母で消える素数 $`p=i`$ は、二項係数にその素数が残る場合だけ完全付値を復元する。

隣接する非最大行が少なくとも一組あるとする。さらに $`s<i-1,t=s+1`$ で $`t`$ が非最大行、
行 $`s`$ の候補素数の完全冪 $`q`$ について、標準桁多項式が

```math
F=s+aX+bX^m,\qquad J=u+cX+dX^m,
\quad a,b\ge1,\quad a+b\le M_0,\quad m\ge2,
\quad0\le u\le s,\quad0\le c\le a,\quad0\le d\le b
```

となるとする。$`n=F(q),j=J(q)`$。二つの端点 $`(c,d)=(0,0),(a,b)`$ は添字の範囲から不可能。
一位置の形 $`F=s+aX`$ も以下の上限に含める。
正整数 $`C,D`$ について、$`D'_t\mid C`$、全非最大行で $`D'_r\le D`$ が分かっているとする。
一般には $`C=D=L_i`$ としてよい。

以下を置く。

```math
Q_0=2C(s+M_0+t)^{t+1}M_0^{t(t+1)+1},\qquad
E=M_0(M_0+t+1),\qquad K=CE^{t+1},\qquad h=i-1,
```

```math
U=\max\left\{
s+M_0Q_0^{t+1},\quad t+K^{t+2},\quad
h+D\{M_0(t+h)\}^{i}
\right\}.
```

**補題。上の仮定を満たす反例なら $`n\le U`$。**
素数の個数、完全付値の指数、$`m`$ には上限を仮定しない。
必要なのは、その一つの底における非零の正次数桁が二か所以内で、重みが $`M_0`$ 以下であること。

## 2. 低次数

非最大行 $`t`$ の分配により

```math
F(q)-t\mid C\prod_{v=0}^t(J(q)-v).
```

既存の逆順モニック整数除算の補題に $`H=F(1)\le s+M_0`$ を入れる。
$`m\le t+1`$ なら

```math
q\le2C(H+t)^{t+1}(H-s)^{tm+1}\le Q_0,
\qquad n\le s+M_0q^{t+1}\le s+M_0Q_0^{t+1}.
```

一位置の場合も次数1なので同じ粗い上限でよい。
この段階で終結式が非零と仮定していない。
例えば $`a=1,b=2`$、偶数 $`m`$ では $`bX^m+aX-1`$ が負の根 $`-1`$ を持つ。

## 3. 高次数を一次式へ圧縮する

$`A=F-t`$、$`k=bc-ad`$、$`\ell_v=d+b(u-v)`$ と置く。
全次数について整数恒等式

```math
b(J-v)=dA+kX+\ell_v
```

が成り立つ。元の整除性へ $`b^{t+1}`$ を掛けてから $`A(q)`$ を法として還元すると

```math
A(q)\mid C\prod_{v=0}^t(kq+\ell_v).
```

$`|k|\le ab\le M_0^2`$、$`|\ell_v|\le b(t+1)\le M_0(t+1)`$ なので

```math
|kq+\ell_v|\le Eq\qquad(q\ge1).
```

すべての一次式の値が非零なら

```math
q^m\le A(q)\le Kq^{t+1}.
```

$`m\ge t+2`$ では $`q\le K`$、そして $`n\le t+K^{t+2}`$。
これにより指数を先に切る必要がなくなる。

## 4. 零値の共鳴も有限化する

ある $`v`$ について $`kq+\ell_v=0`$ なら

```math
b(j-v)=d(n-t).
```

$`d=0`$ なら $`j=v\le t<i`$、$`d=b`$ なら $`n-j=t-v<i<j`$ となって不可能。
したがって $`0<d<b`$。$`g=\gcd(b,d),B=b/g,A_0=d/g`$ とすれば

```math
Bj-A_0n=\delta:=Bv-A_0t,
\qquad 0<A_0<B\le M_0,\quad \gcd(A_0,B)=1,\quad |\delta|\le Bt.
```

セル $`(r,w)`$ の因子は整数 $`\delta+A_0r-Bw`$ を割る。
この整数が零となる行 $`r`$ は、法 $`B\ge2`$ の一つの剰余類だけ。
隣接する非最大行は両方ともその類には入らないので、零値を一つも持たない非最大行 $`r`$ がある。
この行の全セルを掛け合わせて

```math
Q'_r\mid\prod_{w=0}^r(\delta+A_0r-Bw),\qquad
Q'_r\le\{M_0(t+h)\}^{r+1},\qquad
n\le h+D\{M_0(t+h)\}^{i}.
```

これで共鳴を含む全ケースが閉じ、補題を証明した。
多項式の負の共通根と整数評価での零値を区別しており、全終結式の非零性には依存しない。

## 5. 全添字と小添字への適用範囲

既存の数え上げにより $`i\ge10`$ では必ず隣接する非最大行がある。
その一組 $`s,t`$ を選べば、本補題は行 $`s`$ の任意の候補素数の完全冪に適用できる。
$`n>U`$ の反例では、その行の全ての底において、正次数桁が三か所以上か、重みが $`M_0`$ を超えなければならない。
これは素数個数の上界を要求しない必要条件である。

$`i=5`$ の既存支持01では非最大行2・3・4があるので、$`s=2,3`$ の両方へ適用できる。
[独立の重み4二位置稿](../i5/i5_independent_attack_2026-10-03.md)は、特定の係数の非零終結式を用いて本稿の粗い定数を改善する。

一般の反例について、二位置の小さい重みを持つ底が必ず存在するという証明はない。
桁の三位置以上、無界の重み、一般数値域から完全多項式分配への移行は残る。
本補題を問題699全体の有限化と読み替えてはいけない。
