# Proposition 6.1 による巨大中間範囲の接続

2026年10月4日。対象は元の問題699の p≥i 版である。
本稿は i=16,19,22,25 の範囲

```math
10^87≤n<exp(10^6)
```

に反例がないことを示す。**これだけで四添字の全 n を閉じたとは述べない。**
無限尾部の開始点をこの中間範囲内へ入れる明示評価が別に必要である。

## 1. 全15組の最大余因子条件

外部入力は Bennett--Filaseta--Trifonov,
[On the factorization of consecutive integers](https://people.math.sc.edu/filaseta/papers/BFTpaper0207.pdf),
Proposition 6.1（印刷頁21、PDFの0始まり頁番号20）の後半である。

2≤p<q≤13 の全素数対について、
差の絶対値が100以下、10,000<p^e a<exp(10^6) で、
max(a,b)≤min(p^e a,q^f b)^(1/3) なら、明示された93組に限られる。
表の第一成分の最大値は2,693,359,375であり、相手の成分との差は100以下なので、
両成分に対する安全な例外上限として3,000,000,000を使う。
外部の有限計算の証明自体を本稿のコードが再実行したという意味ではない。

h=i−1、小素数の最大付値行r_p、余因子a_p、積Pを
[既存のBFTグラフ稿](bft_pair_graph_closeout_six_indices_2026-10-04.md)と同じく定義する。

```math
p^{E_p} a_p=n−r_p,  0≤r_p≤h,  P=∏_{p<i}a_p.
```

i≥14、h≤100、n−h>3·10^9、n<exp(10^6) なら、六素数2,3,5,7,11,13の全15組で

```math
max(a_p,a_q)>(n−h)^(1/3).                       (1)
```

が成立する。最大行の相異性を仮定しない。
同じ行を選ぶ二素数の場合は、a_pa_q≥n−r から
max(a_p,a_q)≥√(n−r)>(n−h)^(1/3) と直接確認できる。

六個のa_pのうち、(n−h)^(1/3) 以下のものは高々一つである。
二個あればその二頂点の辺が(1)に反する。
よって少なくとも五個が閾値より厳密に大きく、

```math
P>(n−h)^(5/3).                                 (2)
```

が得られる。他の小素数の余因子は1以上であり、積下界を弱めない。

## 2. 四添字の厳密な中間範囲排除

三方向被覆の記号 h,m,c_i,b,d,S,D と A=i!/c_i を使う。
反例は普遍的な上界

```math
P^d≤A^d 4^(−S)(n/(n−h))^(id)n^D
```

を満たす。N=10^87 と置くと、全四添字で N>2hid および N>10hd。
二回の Bernoulli 評価と(2)により

```math
P^(3d)>n^(5d)/2,
P^(3d)<8 A^(3d)n^(3D)/4^(3S).
```

従って反例には

```math
4^(3S) n^(5d−3D)<16 A^(3d)                      (3)
```

が必要である。

|i|m|d|S|D|κ=5d−3D|A<10^eのe|Nでの粗比較の十進指数余裕|
|---:|---:|---:|---:|---:|---:|---:|---:|
|16|6|15|55|15|30|13|2122|
|19|7|18|78|18|36|18|2298|
|22|8|21|105|21|42|20|2581|
|25|9|24|136|24|48|24|2690|

4^5>10^3、16<10^2、A<10^eを用いれば、(3)の左右を

```math
4^(3S) N^κ >10^(87κ+floor(9S/5)),
16 A^(3d)<10^(2+3de)
```

で反対向きに比較できる。表の余裕は
87κ+floor(9S/5)−2−3deであり、全て正である。
κ>0なので、全 n≥N でこの矛盾が保たれる。
Proposition 6.1の上限内である n<exp(10^6) と合わせ、所定の中間範囲を閉じる。

[結果](../../data/results/verification_bft_proposition61_intermediate_bridge_2026_10_04.json)
は15辺の全64高低パターン、四添字の全重みセル、
二つのBernoulli条件、例外上限、粗い厳密整数比較を再生する。
無限尾部はこの検算結果の結論に入れていない。

## 3. 無欠落に接続する条件

既存の n≤10^87 の有限定理と、本稿の中間範囲は接続する。
残る必要条件は、別の明示的な無限尾部定理が n≥exp(10^6) で適用できること。

BFT Theorem 2.4 が min(n−r_p,n−r_q)≥x0 を要求する場合、
log x0≤999999 を示せば十分である。
e>2、e^999999>h から

```math
n≥e^1000000 ⇒ n−h>e^999999≥x0.
```

これで中間範囲の厳密上限と尾部の下限の間に空白はない。
log x0≤10^6という評価だけを得て、nとn−r_pの差hを無視してはならない。
1単位の余裕は便利な十分条件であり、実際には
e^1000000−x0>h を直接証明してもよい。

## 4. bounded-bootstrap の計算量と使い分け

i=16ではβ=D/d=1、m=6である。
有限上限Nの下で、最小二余因子の積上限Bと個別係数上限A2は
定数を除いてそれぞれN^(1/3)、N^(1/5)となる。
係数全範囲を走査する必要はないが、既存実装は依然として素数冪の指数対を列挙する。

L=log N、t=e log p、u=f log q とすると、一次の大きさ条件は概ね

```math
2L/15<t,u≤L,   |t−u|≤L/5.
```

この領域の面積は(23/75)L²である。
したがって、六素数の指数対数は

```math
(23/75)L² ∑_{p<q≤13, p,q prime}1/(log p log q)+O(L)
```

の規模になる。これは計算コストの診断であり、数論上の不可能性の証明ではない。

L=10^6なら、おおよそ2.23·10^12指数対と、
31個の差δを使う約6.92·10^13剰余更新となる。
さらに既存実装は各素数冪を整数としてリスト保存するため、
ビット本体だけでおおよそ0.38TBの規模となる。
巨大整数の乗除算・逆元のコストはこの見積りに含めていない。

したがって、現在の二指数ループをexp(10^6)まで単純に延長する手順は採用しない。
この大きな範囲は第2節の数学的不等式で直接覆い、
有限CRTは、明示尾部とProposition 6.1の間に本当に小さな未被覆区間が残る場合だけに用いる。
BFT論文自身の指数ブロックによる計算法は別の有限アルゴリズムであり、
既存の二指数ループを高速化したことにはならない。
