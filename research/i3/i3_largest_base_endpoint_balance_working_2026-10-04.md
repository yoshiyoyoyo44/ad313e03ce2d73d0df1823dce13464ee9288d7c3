# 最大完全素数冪の底：任意次数因子の評価と端点次数の釣合い

2026-10-04。新しい条件付き作業補題。一般数値領域から完全分配を得る証明ではない。
端点次数の釣合い、固定商次数への拡張、一般F−2の因子評価について、
独立した別エージェントが紙上証明を再導出・監査し、検算も再生した。

## 1. 最大底における次数の上限

$\delta\in\{1,3\}$ とし、$(n-1)/\delta$ の完全素数冪の最大値を $q$ とする。
$L(r)=\operatorname{lcm}(1,\ldots,r)$ と置くと

```math
(n-1)/\delta\mid L(q),\qquad n\le4L(q)<4\cdot16^q.
```

$L(r)\le16^{r-1}$ の初等的な証明は次の通り。
$k=\lceil r/2\rceil$ に対して、$L(2k)/L(k)$ は $\binom{2k}{k}$ を割る。
実際、増える各素数付値は高々1であり、対応する完全素数冪 $p^e\in(k,2k]$ は
中央二項係数の付値公式に正の項を一つ与える。
従って $L(r)\le4^kL(k)$。
$6\lceil r/2\rceil\le4r$ ($r\ge2$) より帰納法で所要の上界が従う。

標準 $q$ 進多項式 $F$ の次数を $m$ とすると $q^m\le n$。
従って $q\ge2^{14}$ なら

```math
m+1\le\frac{q\log16+\log4}{\log q}+1
\le\frac{2q}7+\frac87\le\frac{3q}{10}.\tag{1}
```

ここでは桁和や素数個数の上限を仮定していない。
$q<2^{14}$ の枝も $n<4\cdot16^{2^{14}}$ と有効有限になるが、その巨大な有限域を排除したとは主張しない。

## 2. 正係数残余の全因子に共通する評価

標準桁 $F_0=1,F_1\ge1,0\le F_k<q$ において

```math
F-2=(aX-1)D,\qquad a\ge2,\quad D(0)=1
```

と整数係数分解されるとする。
$D$ の全係数は正整数で $D_k<q/(a-1)$。
従って Mahler 測度 $M$ は

```math
M(D)\le\|D\|_2<\frac{q\sqrt{m+1}}{a-1}.\tag{2}
```

$D$ は正実根を持たない。$H\in\mathbb Z[X]$ を $D$ の任意の非定数因子とし、
$H(0)=1$、最高係数 $c>0$、次数 $r$ とする。
$M(H)\le M(D)$。非実根は共役対になり、各対の絶対値を $\rho$ とすると
$\prod_{\rho\ge1}\rho\le\sqrt{M(D)}$。
$\sum(x_i-1)\le\prod x_i-1$ for $x_i\ge1$ より、非実根の絶対値の総和は

```math
\sum_{\text{nonreal roots}}|\alpha|
\le r+2(\sqrt{M(D)}-1)<m+1+2\sqrt{M(D)}<q/2.\tag{3}
```

最後に (1),(2) と $q\ge2^{14}>10^4$ を使った。
具体的に $\sqrt{M(D)}<q^{3/4}$、従って $2\sqrt{M(D)}<q/5$ である。
実根は負なので、その因子 $|q-\alpha|/q$ は1以上。
非実根について $|q-\alpha|/q\ge1-|\alpha|/q$ を使い、
$\prod(1-t_i)\ge1-\sum t_i$ から

```math
H(q)>\frac12c q^r.\tag{4}
```

上からは、絶対値1以上の根を乗法的に集約する。
$x,y\ge1,q\ge1$ に対し

```math
(1+x/q)(1+y/q)\le(1+1/q)(1+xy/q).
```

従って

```math
H(q)\le c q^r(1+1/q)^r(1+M(D)/q)
<\frac32c q^r\left(1+\frac{\sqrt{m+1}}{a-1}\right).\tag{5}
```

$(1+1/q)^r\le\sum_{k\ge0}(r/q)^k\le10/7<3/2$ を使った。
因子の係数に負数が含まれても (4),(5) は成立する。

### 評価部分は一般の標準F−2にも適用できる

因子の下界だけは $F-2=(aX-1)D$ を仮定する必要がない。
標準桁 $F_0=1,F_1\ge1$ の一般の $F-2$ は正実根を一つだけ持ち、
その根 $\alpha$ は $(0,1]$ にある。
$M(F-2)<q\sqrt{m+1}$ であり、正実根の損失を含めても
非実根と正実根の絶対値の総和は、任意因子Hの次数rに対し
$r+2(\sqrt{M(F-2)}-1)<q/2$ と抑えられる。
負実根は下界に損失を与えない。
従って、最高係数を正にした**任意の整数因子 $H\mid F-2$** に

```math
H(q)>\frac12\operatorname{lead}(H)q^{\deg H}
```

が成立する。定数項は1又は−1を許す。
さらに上界の精密形は

```math
H(q)<\frac32q^{\deg H}\bigl(\operatorname{lead}(H)+\sqrt{m+1}\bigr).
```

この評価の適用には、最大完全素数冪の底 $q\ge2^{14}$ と標準桁だけが必要であり、
完全分配や正実根因子の一次性を仮定しない。

### 一般数値領域への直接の必要条件

一般i=3反例の最大底qとその標準F,Jにおいて、
正実根を含む原始既約因子を $g\mid F-2$ とする。
[既存の正実根・終結式の証明](i3_prime_power_resultant_frontier_2026-10-01.md)により、

```math
g(q)\mid6\prod_{s=0}^2\operatorname{Res}(g,J-s),
\qquad \prod_{s=0}^2\operatorname{Res}(g,J-s)\ne0.
```

従って今回の評価から直接

```math
\operatorname{lead}(g)q^{\deg g}
<12\prod_{s=0}^2|\operatorname{Res}(g,J-s)|
```

が得られる。以前の因子下界で必要だった $q\ge2F(1)-1$ を、この最大底では要求しない。
終結式の値が次数・係数とともに増大する枝はなお残るため、一般反例を排除した結論ではない。

## 3. 第一の数値条件による端点次数の釣合い

標準桁の完全分配

```math
D=B_0B_1B_2,\quad B_t(0)=1,\quad B_t\mid J-t,
\qquad 0\le J_k\le F_k<q,
```

を仮定する。最高係数は正、$4\mid n$、$4\le j=J(q)\le n-4$、
$n=F(q)$、$n-1\mid3j(j-1)$ とする。
元の半分の添字とその補数はこの範囲に入る。
$Q=B_2$、$E=B_0B_1$、$N=\deg Q\ge1$、$d=\deg E\ge1$ と書く。
$s,e$ はそれぞれの最高係数であり $aes<q$。

$P=(aq-1)E(q)$、$R=(j-2)/Q(q)$ は正整数。
$n-2=PQ(q)$ と $j<n$ より $0<R<P$。
$E(q)>6$ は (4) と $d\ge1,q\ge2^{14}$ から従う。
以前の整数商の恒等式は商の次数や係数の符号に依存せず

```math
kE(q)=6+\ell Q(q),\quad\ell\ge1,
\qquad TQ(q)=V,
```

```math
T=3R^2-\ell P,\qquad V=6P+\ell-9R
```

を与える。また

```math
\ell<3R^2/P<3P,\qquad -3P<V<9P.
```

半分を超える補数にも有効な厳密評価は、次の差の恒等式による。

```math
\ell-\frac{3R^2}{P}
=-\frac{3(R-P)(R-2P)}{P(PQ(q)+1)}<0\qquad(0<R<P).
```

$T=0$ なら $V=0$。
二式の消去で $(3R-\ell)(6R-\ell)=0$、$P=\ell/3$ 又は $\ell/12$ となる。
どちらも $\ell<3P$ に反する。
従って $T$ は非零整数であり

```math
Q(q)\le|V|<9P<9aq E(q).\tag{6}
```

(4),(5),(6) を組み合わせると

```math
q^{N-d-1}<27\frac{ae}{s}
 \left(1+\frac{\sqrt{m+1}}{a-1}\right),
```

```math
q^{N-d-2}<\frac{27}{s^2}
 \left(1+\frac{\sqrt{m+1}}{a-1}\right)
\le27(1+\sqrt q)<q.\tag{7}
```

最後の不等式は $\sqrt q\ge128$ から従う。
$N-d\ge3$ なら (7) の左辺は $q$ 以上となり矛盾。
従って

```math
\boxed{\deg B_2\le\deg B_0+\deg B_1+2.}\tag{8}
```

補数 $F-J$ へ移すと完全分配の群 $B_0,B_2$ が交換し、$B_1$ は保存される。
第一の数値条件も $n\equiv1\pmod{n-1}$ から保存される。
上では半分以下の条件を使わず $4\le j\le n-4$ を使ったので、補数にも適用できる。
同様に

```math
\boxed{\deg B_0\le\deg B_1+\deg B_2+2.}\tag{9}
```

一方の端点群が定数の場合、その側の不等式は自明。
その側以外が定数で全残余が一群に入る場合は、$\deg F\ge3$ なら
[既存一群定理](i3_arbitrary_cofactor_closeout_2026-10-02.md)が $4\mid n$ の下で排除する。
補数が半分を超える場合はさらに元の半分の添字へ戻して同定理を適用する。
$\deg F\le2$ なら全残余の次数は1以下なので、次数差2の結論は既に自明である。

## 4. 商の次数を固定すると全次数が有界になる

$R(X)=(J-2)/B_2$ の次数を $t$、最高係数を $v\ge1$ とする。
$B_2(0)=1$ より整数多項式であり、$vs<q$ が標準Jの最高桁から従う。
$M(R)\le M(J-2)<q\sqrt{m+1}$。
根の積を最高係数で割る上の集約を直接 $R$ に使えば

```math
R(q)\le vq^t(1+1/q)^t\left(1+\frac{M(R)}{vq}\right)
<\frac32\bigl(v+\sqrt{m+1}\bigr)q^t
<\frac32\frac{129}{128}q^{t+1}.\tag{10}
```

ここでは $t\le\deg J\le m$、$m+1\le3q/10$、$v<q$、
$\sqrt q\le q/128$ を使った。商に負の係数があってもこの評価は変わらない。
$P=(aq-1)E(q)>(9/20)ae q^{d+1}$ と $ae\ge2$ より

```math
1\le\ell<\frac{3R(q)^2}{P}
<\frac{15}{ae}\left(\frac{129}{128}\right)^2q^{2t-d+1}
<8q^{2t-d+1}.\tag{11}
```

$d\ge2t+2$ なら右辺は $8/q<1$ となり矛盾する。
従って

```math
\boxed{d\le2t+1,\qquad N\le2t+3,\qquad m\le4t+5.}\tag{12}
```

$E,Q$ 非定数の完全分配において、最大底では**商の次数が固定なら全Fの次数が絶対有界**である。
特に二次商は $d\le5,N\le7,m\le13$ に限られる。
この bound は恣意的な次数打切りではなく、第一条件と最大底から得た必要条件である。
商の次数自体が増大する枝は排除していない。

## 5. 義務の境界

この補題は最大底での任意次数・係数符号を許す完全分配を制限する。
両端の次数差と固定商次数での全次数を抑えるのであって、釣り合った三群を排除してはいない。
数値の素数冪分配を多項式全体の整除へ持ち上げる証明も得ていない。
