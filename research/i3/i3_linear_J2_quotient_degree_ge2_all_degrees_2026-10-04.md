# J−2 の商が一次の場合：残余次数2以上の全域排除

2026-10-04。標準桁・完全分配に関する条件付き定理。
元の問題699の完全解決、または一般の i=3 の完全解決を主張しない。

## 定理

奇数 $q\ge5$ と整数多項式 $F,J,E,Q$ が次を満たすとする。

```math
F_0=1,\quad F_1\ge1,\quad 0\le J_k\le F_k<q,
\qquad F-2=(aX-1)E Q,\quad a\in\mathbb Z_{>0},
```

```math
E(0)=Q(0)=1,\quad \deg Q=N\ge1,\quad\deg E=d\ge2,
\qquad J=2+(vX-h)Q,\quad v\in\mathbb Z_{>0},\ h=2-J_0\in\{1,2\}.
```

$EQ=D=B_0B_1B_2$ は全重複度を含む完全分配であり、
$Q=B_2\mid J-2$、$E=B_0B_1$、$B_0\mid J$、$B_1\mid J-1$ とする。
各群の定数項は1。従って $E\mid J(J-1)$、$E$ は正実根を持たない。

このとき

```math
F(q)-1\mid3J(q)(J(q)-1)
```

は不可能である。$N,d$ に次数上限はなく、$q$ の素数冪性や $4\mid F(q)$ を使わない。

## 共通の準備

$D$ の全係数は正整数。実際、最高次から
$F_k=aD_{k-1}-D_k\ge0$ を逆向きに解けばよい。
$Q$ の全係数も正整数である。最高次係数 $s>0$ から
$J_k=vQ_{k-1}-hQ_k\ge0$ を逆向きに解けばよい。

$L=\operatorname{lead}(D)=es\ge1$、$e=\operatorname{lead}(E)>0$ と置く。
$D_1=a-F_1\ge1$ より $a\ge2$。
$Q_1\ge1$ より $v\ge h$。
標準桁を $X=1/a$ で評価すれば $0<J(1/a)<2$ であり、$Q(1/a)>0$ だから $v<ha$。
最高次桁は $aL<q$ と $vs<q$ を与える。

$n=F(q),j=J(q)$、$P=(aq-1)E(q)$、$R=vq-h>0$ と置く。
第一条件と $\gcd(E(q),n-1)=1$ から

```math
\frac{3j(j-1)}{n-1}=kE(q),\qquad k\in\mathbb Z_{>0}.
```

$j\equiv2\pmod{Q(q)}$、$n-1=PQ(q)+1$ なので

```math
kE(q)=6+\ell Q(q),\qquad\ell\in\mathbb Z.
```

$E(q)>6$ であれば $\ell\ge1$。
$Q(q)>q\ge5$、$h\ge1$ により $j/Q(q)<vq$、$(j-1)/Q(q)<vq$。
従って

```math
0<\ell<\frac{3v^2q^2}{(aq-1)E(q)}.\tag{1}
```

## d=2

[二次残余の全次数証明](i3_quadratic_group_linear_residual_all_degrees_2026-10-04.md)
が、二次一群と二つの一次群を全て排除している。
一群の場合は二段の整数合同から $q\le70$ を導き、導かれた全有限域12,258行を排除する。
二群の場合は (1) と $q>abcs$ から $\ell<1$、または $J(-1)$ の整数性に矛盾する。

## d>=3：次数を消す評価

$D$ の正係数性と $j<q^{N+2}$ から

```math
D(q)>Lq^{N+d},\qquad
Q(q)=\frac{j-2}{R}<\frac{q^{N+2}}{R},\qquad
E(q)>LRq^{d-2}.\tag{2}
```

$R=vq-h\ge v(q-1)\ge4$ なので $E(q)>20>6$。
(1)、(2) より

```math
\ell<\frac{3v^2q^{4-d}}{L(vq-h)(aq-1)}.\tag{3}
```

$d\ge3$ では右辺は $d=3$ の値以下。
$v\le2a-1$、$vq-h\ge v(q-1)$、
$(2a-1)/(aq-1)<2/q$ から

```math
\ell<\frac{3(2a-1)q}{(q-1)(aq-1)}<\frac6{q-1}.
```

奇数 $q\ge7$ なら $\ell<1$ で矛盾する。

## q=5 の唯一の例外も排除

$aL<5$、$a\ge2$、$vs<5$、$h\le v<ha$、$s\mid L$ より、
必要パラメータ $(h,a,L,s,v)$ は19行だけである。
$d=3$ における (3) の上界が1以上となるのは

```math
(h,a,L,s,v)=(2,2,1,1,3),\qquad\frac{15}{13}
```

の一行だけ。$d\ge4$ では更に $5^{d-3}$ で割るので、この行も $\ell<1$。
従って $d=3$ のこの一行だけを調べればよい。

$D_1=a-F_1$ は正整数で $a=2,F_1\ge1$ だから $D_1=1$。
$J_1=3-2Q_1\ge0$ と $Q_1\ge1$ より $Q_1=1$。
従って $E_1=D_1-Q_1=0$。
$L=es=1$ より $e=s=1$ なので

```math
E=1+wX^2+X^3,\qquad w\in\mathbb Z.
```

$w\le-2$ なら正の数 $x=-2w/3$ で
$E(x)=1+4w^3/27<0$ となる。
$E(0)=1$、最高次係数正より正実根が生じ、完全分配の仮定に反する。
従って $w\ge-1$、$E(5)\ge101$、$P=9E(5)\ge909$。
この例では $R=13$、$j/Q=13+2/Q<14$ なので (1) を直接使っても

```math
\ell<\frac{3\cdot3^2\cdot5^2}{9\cdot101}
=\frac{75}{101}<1,
```

となり矛盾する。これで全 $d\ge3,N\ge1$ が閉じる。

## d=1への接続

[一次残余の全次数証明](i3_linear_J2_quotient_degree1_bge2_all_degrees_2026-10-04.md)
が $E=1+bX,b\ge2$ を全次数で排除した。
そこでは $b\le6,N\le3$ を先に証明し、導かれた有限域596整数行に許される商がないことを確認する。
さらに $\gcd(q,(n-1)/q)=1$ を加えれば $b=1$ も全次数で閉じる。
これは $q$ が $n-1$ の完全素数冪である元の設定に含まれる条件である。

従って、完全付値条件を加えた標準桁・完全分配では、
**$\deg(B_0B_1)\ge1$、$\deg B_2\ge1$、$(J-2)/B_2$ が一次の枝は全次数で排除された。**
一次残余の有限部も、[lambdaから先に解く独立検算](../../scripts/audit_i3_linear_J2_quotient_degree1_independent.py)
で再生し、同じ596整数行と0候補を確認した。

$d=0$、$N\ge2$ については、$4\mid n$ と添字の範囲も加えれば
[既存の任意共有因子の一群定理](i3_arbitrary_cofactor_closeout_2026-10-02.md)が適用できる。
**$d=0,N=1$ はその旧定理の次数仮定の外であり、ここには含めない。**

残る義務は、一次商の $d=0,N=1$、二次以上の商、
$F-2$ の正実根因子が一次でない場合、標準桁での完全分配を持たない一般数値の場合である。
