# i=3・次数4の完全分配：三一次群の b>t>c を全排除

2026-10-04、研究中の証明。**元問題の完全解決ではない。**
一般数値反例から以下の多項式分配を得ることは、まだ証明していない。
ここでは既存の標準桁の条件付き完全分配の一順序を閉じる。

## 仮定

```math
F-2=(aX-1)D,
\quad D=(1+bX)(1+cX)(1+tX),\quad b>t>c\ge1,
```

```math
\deg F=4,\quad \deg J=3,\quad J_0=0,
\quad F_0=1,\quad 1\le F_1,\quad 0\le J_k\le F_k<q,
```

```math
1+bX\mid J,\qquad1+cX\mid J-1,\qquad1+tX\mid J-2,
\qquad F(q)-1\mid3J(q)(J(q)-1).
```

$a,b,c,t,q$ は正整数。底を素数冪に限定せず矛盾を示す。

## 商と低桁の必要合同

```math
J=X(1+bX)(v+wX),\quad v\ge0,\ w>0,
\quad A=(F-1)/X,\quad K=\frac{J(J-1)}{X(1+bX)(1+cX)}.
```

$v,w$ は整数、$K$ も整数多項式。
$qA(q)=(aq-1)D(q)+1$ から $\gcd(A(q),D(q))=1$。
従って第一数値条件は $A(q)\mid3K(q)$ を与える。
$k=3K(q)/A(q)$ は正整数で、$K_0=-v$ より

```math
q\mid kF_1+3v.
```

また $a\ge b+c+t+v$、$q>abct$。

次の正の差を証明すれば、合同の右辺が $0$ と $q$ の間に入って矛盾する。

```math
P(q):=(q-3v)A(q)-3F_1K(q)>0.
```

## 全パラメータを覆う正係数証明書

$h=c,d=b-t,e=t-c$ とする。三者は正整数。
根での二つの条件から

```math
(c-b)(w-vc)=c^3,\qquad(t-b)(w-vt)=2t^3.
```

従って

```math
\Delta=de(d+e),\quad
V=2t^3(d+e)-c^3d,\quad W=Vc-c^3de,
\qquad v=V/\Delta,\quad w=W/\Delta.
```

$x=a-(b+c+t+v)\ge0$、$y=q-abct-1\ge0$ を導入する。
$P(q)$ の定数項は0であり、$P(q)/q$ は三次式。

```math
c\Delta^5\frac{P(abct+1+y)}{abct+1+y}
=C_3(h,d,e,x)y^3+C_2(h,d,e,x)y^2+C_1(h,d,e,x)y+C_0(h,d,e,x).
```

[厳密検算器](../../scripts/audit_i3_three_linear_order_2026_10_04.py)は、この恒等式を
別の評価式から分母を払った多項式恒等式として検証する。
さらに次の7領域で、各 $C_i$ の係数と定数項が全て正であることを検証する。
各領域の下端から変数を非負整数だけ動かすので、上限を設けない証明である。

| 領域 | $d,e$ の範囲 |
|---|---|
| $h\ge4$ | $d,e\ge1$ |
| $h=1$ | $d\ge2,e\ge1$ |
| $h=1$ | $d\ge1,e\ge4$ |
| $h=2$ | $d\ge2,e\ge1$ |
| $h=2$ | $d\ge1,e\ge2$ |
| $h=3$ | $d\ge2,e\ge1$ |
| $h=3$ | $d\ge1,e\ge2$ |

全28係数多項式は整数演算で生成し、正係数・正定数項を確認した。
係数リストのハッシュ、項数、最小係数は

## 残る五つのパラメータと一つの整数型

被覆されない $(h,d,e)$ は

```math
(1,1,1),(1,1,2),(1,1,3),(2,1,1),(3,1,1).
```

順に $v=31/2,161/6,511/12,50,229/2$。
整数係数で可能なのは一型だけである。

```math
(b,c,t,v,w)=(4,2,3,50,96).
```

ここでは標準桁条件から $a\ge59,q\ge26a-23$、

```math
A=(a-9)+(9a-26)X+(26a-24)X^2+24aX^3,
\quad K=-50+2504X+14592X^2+18432X^3.
```

$\lambda=2304/a$ とすると $a(\lambda A-3K)$ の三係数は

```math
2454a-20736,\quad13224a-59904,\quad16128a-55296,
```

であり、$a\ge59$ で全て正。従って $1\le k<2304/a$。
低桁合同の右辺は

```math
0<k(a-9)+150<2454<2q.
```

よって $q=k(a-9)+150$。$q\ge26a-23$ と合わせて $59\le a\le95$。
全整数 $a,k$ をこの範囲で列挙し、$q$ の下限を満たす全147組について
$kA(q)\ne3K(q)$ を整数演算で確認した。
底や素数の試験範囲を外挿したものではなく、証明で導いた全有限域の排除である。

## 結論と残る義務

上の条件付き標準桁モデルで、$J_0=0$、三一次群、$b>t>c$ の順序は不可能。
他の順序、$J_0=1$、一般の数値反例からの分配移行は、この証明では閉じない。
