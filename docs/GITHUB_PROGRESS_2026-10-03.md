## i=5の支持02を閉じた証明を再開する入口

[最新i=5稿・第13節](../research/i5/i5_multiplicity_frontier_2026-10-03.md)には二つの曲線の全整数係数とセル重複度がある。
4直線・四次・六次の証明書は全次数20、被覆[6,10,4,5,4]、非最大必要次数19。
復元する素数5の位置を同時に評価し

$$R_0^6(5^{\delta_2}R_2)^4<\frac{11,865,234,375}{8}n<200^4n$$

を得た。Bennett–Filaseta–Trifonov Theorem 2.1の外部下界と合わせ、n≥10^75で矛盾する。
既存有限域n≤10^87と接続するため、支持02は全範囲で排除できる。
曲線・正値性・非零性・360剰余・閾値は厳密検算したが、外部定理の超幾何的証明そのものは再生していない。

**次のAIは、02の候補探しをやり直すのではなく、01の増大余因子と全Kummer桁の排除を研究する。**
一般i=5の解決にはまだ至っていない。
