## 全添字に共通する方法

[隣接行の桁降下](../research/general/adjacent_row_digit_descent_2026-10-03.md)では、候補素数の完全素数冪を底にした桁多項式と、隣接行の正の実根を使います。

| 得た結論 | 適用範囲・残る前提 |
|---|---|
| 隣接行の多項式全体の整除を否定 | 本文の桁条件・非最大行の仮定の下。因子の部分共有は残る |
| 数値から多項式へ移る明示的な条件 | 逆順モニック整数除算による条件付き補題 |
| $`n`$ の有効な上限 | 異なる素数の個数 $`k`$ とブロック桁和の最大値 $`H_*`$ が有界な場合 |
| 隣接する非最大行が必ず存在 | $`i\ge10`$。これだけで反例は排除できない |
| 桁の合同条件を全行積へ接続 | 乗法部分群による条件付きの排除原理 |

## i=5：残る一般尾部

一般の場合に残るのは **$`n\gt 10^{87}`$、支持{0,1}、$`n\equiv9,64\pmod{72}`$** です。
支持・セル・桁和の意味は[用語集](GLOSSARY.md)を参照してください。

| 到達点 | 根拠・適用範囲 |
|---|---|
| 支持{0,2}を全排除 | [重複度の証明](../research/i5/i5_multiplicity_frontier_2026-10-03.md)。外部BFT Theorem2.1と有限域の接続を使用 |
| 法72の45類、広い添字域・中央近傍を排除 | [積と直線近傍](../research/i5/i5_global_product_and_affine_exclusions_2026-10-03.md)。全 $`n`$ で $`j\le1.4\cdot10^{57}`$、$`n-2j\le3\cdot10^{31}`$ を被覆 |
| $`n-1,n,n+1`$ のいずれかが完全冪となる全域を排除 | 同稿。底・指数の上限なし。$`n=3^f5^d`$ の族も成立 |
| 重い3行に8セル以下の全880配置を排除 | [分配と5の高桁](../research/i5/i5_odd_sparse_allocation_and_prime5_lift_2026-10-03.md)。少なくとも9セル、各行2セル以上が必要 |
| 奇数9類の付値下限 | 同稿。$`v_3(n)\ge100`$、$`v_2(n-1)\ge112`$。25が連続5整数の一つを割る枝では102・115 |
| 偶数64類の付値下限 | [積と直線近傍](../research/i5/i5_global_product_and_affine_exclusions_2026-10-03.md)。$`v_2(n)\ge156`$、$`v_3(n-1)\ge68`$ |
| 小さい桁和の族を全指数で排除 | [隣接行の桁降下](../research/general/adjacent_row_digit_descent_2026-10-03.md)。重み2以下、二か所の重み3、全底が最小桁和の二族 |
| 少なくとも一つの底で大きい桁和が必要 | 同稿。奇数9類の行2で $`H\ge7`$、偶数64類の行3で $`H\ge8`$ |
| 全底での下限と二位置族の追加排除 | [独立研究](../research/i5/i5_independent_attack_2026-10-03.md)。奇数9類の行3で全候補底に $`H\ge9`$。奇数行3・偶数行2の重み4・6・8、二位置以下を全指数で排除 |

残るのは、素数の個数・桁和・セル分配が増大する一般枝です。
Mahlerの外部定理から得る反例の有限性は**非有効**で、計算できる全域の上限は取得していません。
固定多項式の容量と現在のBFT指数に両立する形式的重みは、手法の限界を示すもので整数反例ではありません。
[4段階の証明と検算](../research/i5/README.md)

## i=3：条件付き分配と一般数値領域

二つの設定を区別します。$`F(0)=2`$ を使う完全な多項式移行の議論と、標準桁の $`F(0)=1`$ を使う数値・完全分配の議論は同じ仮定ではありません。

- **多項式へ移行済みの設定：** 次数8以下の分類・整数評価による排除、任意次数の分配下限と特定の境界の排除。
- **数値領域：** 完全素数冪・両隣接法の終結式による条件付き上限、任意の共有因子を一つの $`J-s`$ に割り当てる族などの排除。
- **標準桁の完全分配：** 残余次数5を排除。[独立研究](../research/i3/i3_independent_attack_2026-10-03.md)で残余次数6・$`\deg F=7,\deg J=4`$ の有限境界も全排除。残余次数6では $`\deg F=4,\deg J=3`$ の低次数枝が残る。

一般数値領域からの多項式移行、九次以上の一般分配、複数群への共有や増大する桁和は残ります。
[前提から読む](../research/i3/README.md) · [二つの設定の詳細](AI_HANDOFF_2026-10-02.md)
