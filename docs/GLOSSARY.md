## 元の問題の記号

| 記号・用語 | 意味 |
|---|---|
| $`n`$ | 二項係数の上の整数 |
| $`i,j`$ | 下の添字。$`1\le i<j\le n/2`$ |
| $`\binom ni`$ | $`n`$ 個から $`i`$ 個を選ぶ方法の数。$`n!/(i!(n-i)!)`$ |
| 素因数 | 整数を割る素数 |
| 共通素因数 $`p\ge i`$ | 二つの二項係数を割り、添字 $`i`$ 以上である素数 |
| $`a\mid b`$ | $`a`$ が $`b`$ を割り切る |
| $`n\equiv r\pmod m`$ | $`n`$ を $`m`$ で割った余りが $`r`$ |
| $`v_p(m)`$、付値 | $`m`$ を割る $`p`$ の最大の指数。例：$`v_3(45)=2`$ |
| 完全素数冪 $`q=p^{v_p(m)}`$ | その整数に含まれる $`p`$ の付値を全部取った冪 |
| 完全冪 | $`a^e`$ の形の整数。通常この研究では $`a,e\ge2`$ |
| 尾部 | 既に被覆した有限範囲より先の大きな $`n`$ |

## 行・支持・セル

二項係数の分子の連続整数を「行」として扱います。行 $`s`$ は通常 $`n-s`$ を表します。
ある素数について、どの行で付値が最大かを調べ、その行に素数を割り当てます。

| 用語 | 読み方 |
|---|---|
| 最大行 / 非最大行 | その素数について付値が最大の行 / それ以外の行。正確な規則は各稿で定義 |
| 支持{0,1}、支持01 | 小素数の最大付値行が0・1である配置。数値の集合や添字全体の成立範囲ではない |
| セル $`B_{s,u}`$ | 行 $`n-s`$ の素数冪のうち、条件により $`j-u`$ 側へ割り当てる積 |
| 非自明なセル | 積が1より大きいセル |
| 8セル以下の排除 | 該当する仮定の下で、非自明なセルが8個以下の全配置を閉じること |
| 復元余因子 $`A,B,R_s`$ | 小素数を除いた因子や、除去した一因子を戻した積。定義は稿ごとに異なる |

## 桁と多項式

素数冪 $`q`$ を底として整数を書くと、桁が多項式の係数になります。
例：$`n=1+2q+q^3`$ なら、その桁多項式は $`F(X)=1+2X+X^3`$ で $`F(q)=n`$ です。

| 記号・用語 | 意味・注意 |
|---|---|
| $`F,J`$ | 通常は $`n,j`$ の桁から作る多項式。標準桁と変換後の設定を区別する |
| 桁和 $`H`$ | 桁の係数の総和、すなわち $`F(1)`$ |
| 非定数桁の重み $`M`$ | 隣接行の稿では $`M=H-s`$。非定数係数の総和 |
| $`H_*`$ | 複数の素数冪底にわたる桁和の最大値 |
| $`k`$ | 該当する行因子に含まれる異なる素数の個数。付値や次数ではない |
| 次数 | 多項式で係数が0でない最大の指数 |
| Kummer条件 | 素数 $`p`$ での繰り上がりを通じ、二項係数の付値を調べる条件 |
| 完全素数冪進の桁条件 | $`q=p^e`$ でまとめた必要条件。これだけで全 $`p`$ 進Kummer条件の逆を保証しない |
| 多項式への移行 | 数値の整除条件から、多項式の整除条件を導くこと。追加の条件が必要 |
| 完全分配 | 該当する因子を重複度込みで全て指定された群へ割り当てること |
| 部分共有 | 一部の因子だけが共有される配置。完全分配の定理がそのまま使えるとは限らない |
| 終結式 | 二つの多項式の共通根に関わる整数量。0になる場合は別処理が必要 |
| BFT | Bennett–Filaseta–Trifonovの外部定理。適用条件と定数は各証明に記載 |
| 容量 | 局所零点の重複度と全次数の費用から、積の大きさを制限する評価 |

$`i=3`$ の $`F(0)=2`$ の設定と、標準桁の $`F(0)=1`$ の設定を混ぜないでください。[詳しい前提](AI_HANDOFF_2026-10-02.md)

| 表現 | 意味 |

| 全 $`n,j`$ で成立 | その添字に許される全ての組を被覆 |
