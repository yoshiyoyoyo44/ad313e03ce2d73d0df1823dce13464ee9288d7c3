## 最新の成果

- **全添字に共通する桁降下と、全素数の行積との結合を証明。** 隣接行の正の実根から条件付き補題と有効上限を得ました。i≥10では隣接する非最大行が必ずあります。i=5では桁の重み2以下、さらに二か所の非零桁を持つ重み3の族を全指数で排除。全素数底の条件を法24で乗法的に結び付け、素数の個数を制限せず二つの最小桁和の族も閉じました。奇数9類の行2には少なくとも一底で桁和7以上、偶数64類の行3には8以上が必要。[全添字の補題と適用](research/general/adjacent_row_digit_descent_2026-10-03.md)。一般の大きな桁和は残り、全添字の解決ではありません。
- **i=5の880分配を排除し、奇数の付値を強化。** 重い3行に非自明なセルが8個以下の全配置を整数多項式・終結式で閉じ、反例には少なくとも9セルが必要と示しました。5の高桁条件から、奇数尾部には $v_3(n)\ge100,v_2(n-1)\ge112$ が必要。25が連続5整数の一つを割る場合は102・115へ強化します。[880証明書と高桁条件の新稿](research/i5/i5_odd_sparse_allocation_and_prime5_lift_2026-10-03.md)。現在のBFT指数と固定多項式の全次数容量だけでは閉じないことも全次数で証明。奇数9類・一般i=5は未解決です。
- **i=5で、n−1・n・n＋1のいずれかが完全冪となる全域を閉鎖。** 平方根での近接冪定理と、奇数指数の因数分解・LTEを使い、底と指数を制限せず排除しました。帰結として $n=3^f5^d$ の全f,dも閉じました。[新証明・第9節](research/i5/i5_global_product_and_affine_exclusions_2026-10-03.md)。既存有限域との接続を含む整数閾値の検算が通過。一般i=5と問題全体は未解決です。
- **i=5の45類を全排除し、小さい添字と中央近傍を閉鎖。** 残る法72の類は9・64です。全nで $j\le1.4\cdot10^{57}$、$n-2j\le3\cdot10^{31}$、1/3・1/4などの有理直線近傍を閉じました。残る尾部には $v_2(n)\ge156,v_3(n-1)\ge68$ または $v_3(n)\ge99,v_2(n-1)\ge108$ が必要です。復元余因子にも $AB<70n^{3/5}$ と不均衡を強制しました。[積の下界と直線近傍の新証明](research/i5/i5_global_product_and_affine_exclusions_2026-10-03.md)。古典的外部定理を使えば反例の非有効な有限性も得られますが、数値上限は未取得。一般i=5と問題全体は未解決です。
- **i=5 の最後の支持は {0,1}。** 四次・六次の多重零点から、支持{0,2}で復元余因子 $B=5^{\delta_2}R_2<200n^{1/4}$ を得ました。外部Bennett–Filaseta–Trifonov Theorem 2.1と併用して $n\ge10^{75}$ で矛盾し、既存有限域と合わせ支持{0,2}を全排除しました。[i=5 の新証明・第13節](research/i5/i5_multiplicity_frontier_2026-10-03.md)。一般i=5は未解決で、$n>10^{87}$ の支持{0,1}のみが残ります。原本・全9証明書・外部依存・残る境界を保存しています。
- **任意の二次商の一割当てを次数6以上で排除。** $F-2=(aX-1)(bX+1)B$、$B\mid J-s$ は、負係数を許す任意の B と全 s で第一条件だけから排除しました。導かれた993配置・12,308商を二方式で検算。今回 $B\mid J-1$ は次数5まで全底で延長しました。[任意の二次商](research/i3/i3_quadratic_cofactor_single_allocation_closeout_2026-10-02.md)。複数割当てと一般の i=3 は残ります。
- **六次と奇数半次数の幾何級数で、負の一次因子以外を全共有する枝を閉鎖。** 六次の全 $b\ge2$ は第一条件と4、$b=1$ は完全 Q1 と全奇素数 Kummer も使います。[六次部分共有](research/i3/i3_sextic_partial_sharing_closeout_2026-10-02.md)、[奇素数接続と高次](research/i3/i3_odd_prime_gluing_and_even_multiplier_2026-10-02.md)。全標準桁多項式の排除ではありません。
- **幾何級数の全共有を分かれた割当てまで分類・排除。** 倍率と次数が互いに素なら、整数根値と分散から全割当てを分類して全次数を数値排除しました。[全共有の分類](research/i3/i3_integral_root_values_and_split_geometric_closeout_2026-10-02.md)。保存済み本文と独立に復元した検算器を保持しています。
- **幾何級数への制限を外し、任意の共有因子を一つの添字へ割り当てる枝を排除。** 三次以上の桁多項式で $F-2=(aX-1)B$、$B\mid J-s$（$s=0,1,2$、重複度込み）なら、$4\mid n$ と $n-1\mid3j(j-1)$ は両立しません。商の全三形を扱い、四次以上は不等式、三次は整数の商・符号・全剰余の合同証明書で閉じました。[任意の共有因子の閉鎖](research/i3/i3_arbitrary_cofactor_closeout_2026-10-02.md)。複数の添字への割当て、不足する重複度、高次の正実根の因子などは残り、一般の $i=3$ は未解決です。
- **一般数値領域で両隣接法の終結式を併用し、幾何級数を共有する族を全排除。** 正実根の一因子から、両法の全非共有部分へ評価を広げました。$F-2=(aX-1)(1+\cdots+X^{m-1})$、$J=cX(1+\cdots+X^{m-1})$ の族は、全 $a\ge2,1\le c<a,m\ge3,q>a$ で反例になりません。数値から多項式への移行を仮定せず、整数の商と七つの判別式で証明しました。[両隣接法と幾何級数の閉鎖](research/i3/i3_adjacent_resultants_and_geometric_closeout_2026-10-01.md)。この族以外の一般の $i=3$ は未解決です。
- **中央群の平方降下で、中央飽和の下限を $h>11u/15$ へ強化。** 二つの平方差から低次数のノルム恒等式を作り、全比率・全次数で示しました。等号も四次式の係数の矛盾で排除しました。中央飽和に限らない追加の三分岐下限もあります。[中央群の二段平方降下](research/i3/i3_central_square_descent_2026-10-01.md)。無限反復や一般の $i=3$ の解決を主張せず、高い差次数、5冪の芯、数値領域への移行は残ります。
- **全半比率分配と、中央飽和の差次数をさらに制限。** $t=1/2$ では飽和・非飽和、均衡・非均衡を含めて $h>(5u-v)/6$、均衡では $h>2u/3$ を証明しました。均衡の中央飽和には全比率で $h>5u/7$ が必要で、等号も偶六次式の平方の矛盾で排除しました。[半比率と中央飽和の続稿](research/i3/i3_half_ratio_and_central_saturation_bounds_2026-10-01.md)。残る高い差次数、5冪の芯、一般数値領域は未解決です。
- **均衡最小境界を全次数で排除し、全分配の下限を強化。** 三つの合成へ分類し、有理原点・2進整数条件・共通素数3で全整数評価を閉じました。さらに、多項式へ移行済みの真の反例に $h\ge\lceil(8u-v)/12\rceil$、均衡では $h>7u/12$ が必要と証明しました。[均衡境界と全分配下限](research/i3/i3_balanced_boundary_closeout_2026-10-01.md)。一般の $i=3$、より高い差次数、奇数芯 $D=5^a,a\ge4$、全数値領域への移行は残ります。
- **5冪の共通5進枝と、25・125の芯の全排除。** 全指数の必要条件を一つの5進定数にまとめ、$n$ の剰余を法 $5^{4a+1}$、純2冪の指数を法 $4D^4$ まで強めました。26件の有限体の証明書で、チェビシェフ型の $D=25,125$ を全整数評価で排除しました。[5冪の続稿](research/i3/i3_five_power_composition_and_local_frontier_2026-10-01.md)。この配置で残る5冪は $a\ge4$。次数25・125の全分配や、一般の $i=3$ を閉じた結果ではありません。
- **全分配のノルム降下と、非均衡境界の任意次数分類。** 最小境界を三つのチェビシェフ型の合成へ送り、二配置を原点の有理性で全排除しました。残る配置も、芯の次数に3または7以上の素因数があれば全整数評価でその素数が共有されます。[全分配とチェビシェフ境界](research/i3/i3_chebyshev_boundary_and_prime_transfer_2026-10-01.md)。5冪の必要条件と小さい芯の排除は上記の続稿で更新しました。他の差次数、一般数値領域は残ります。
- **全残余群の微分恒等式と任意次数のノルム降下。** 二つの残余群が一次の分配で、第三群の次数を任意の $e$ として最小境界 $h=u-e$ を全三配置・重根を含めて排除しました。境界より上にも明示的な次数下限を得ました。[全分配の微分とノルム降下](research/i3/i3_residual_differential_and_norm_descent_2026-10-01.md)。一般分配の全排除と、全数値候補への移行は未解決です。
- **八次を閉鎖し、任意次数の二群分岐をさらに制限。** 最後の八次分岐を厳密な所属証明書と九次式の有理根排除で閉じ、桁多項式の次数8以下の整数評価を排除しました。[八次の閉鎖](research/i3/i3_octic_last_branch_2026-10-01.md)。任意次数の中央二次群、二群分岐の $h=d-2$、二次群の重根も排除しました。[任意次数の続稿](research/i3/i3_residual_and_degree_two_group_2026-10-01.md)。残る境界を漸化式へ送り、次数10・12の $(d-1,d-1,2)$ 分配も閉じました。[微分と漸化式](research/i3/i3_two_group_differential_recurrence_2026-10-01.md)。次数10・12の全分配や一般の $i=3$ を排除した結論ではありません。
- **半次数の境界を任意次数で分類・数値排除。** 四次・五次の式の合成に限られ、内側の全係数の整数性を証明して既存の全整数評価の排除へ戻しました。多項式へ移行済みの数値反例には $h>\deg U/2$ が必要。八次の4+4分配の $h=2$ もここで閉じました。[半次数の合成と排除](research/i3/i3_half_degree_composition_2026-10-01.md)。一般の $i=3$ は未解決です。
- **$i=3$ の数値領域を任意次数で制限。** 完全素数冪を底にまとめ、桁予算を異なる素数の個数で評価しました。正実根を含む因子の終結式から、数値の整除性を多項式全体へ移さずに底を抑えます。桁和と因子の相対次数を制限した枝は、次数・素数・指数・個数が動いても有効に有限化できます。[一般数値領域の続稿](research/i3/i3_prime_power_resultant_frontier_2026-10-01.md)。両量が自由に増える一般枝は残ります。
