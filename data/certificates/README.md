# 有限証明書

[データ案内](../README.md) · [検算手順](../../docs/VERIFICATION.md) · [コード](../../scripts/README.md)

再生器が検査する入力を保存しています。JSON、圧縮JSON、有限体の合同証明書など、形式は証明により異なります。
対応するノートと再生器から読むのが確実です。

| 対象 | 証明・再生器の入口 |
|---|---|
| 重み付き被覆・有限域 | [一般の方法](../../research/general/README.md) |
| i=5の9重複度証明書・880分配 | [i=5の4段階](../../research/i5/README.md) |
| i=3の係数・分配・合同式 | [i=3の案内](../../research/i3/README.md) |
| i=4の5セル・6セル | [i=4の案内](../../research/i4/README.md) |

有理数の緩和配置や探索用の入力もあります。ファイルの存在だけで整数反例や普遍的な排除を意味しません。
生成器で作った証明書は、対応する独立再生器で確認します。
原本のハッシュは[リポジトリ確認](../../scripts/check_repository.py)と各再生器に記録しています。
